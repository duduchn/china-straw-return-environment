# china-straw-return-environment
This repository contains the code, data tables, and raster files for climate–soil classification, field-evidence assessment, and technical validation. The four Jupyter notebooks cover raster data extraction (raster_data_extraction.ipynb), classification (climate_soil_classification.ipynb), evidence support (field_evidence_support.ipynb), and validation (technical_validation.ipynb). Excel and CSV files contain source records, extracted values, regional assignments, and validation results; GeoTIFF files contain spatial outputs. Supporting results are stored in cropland_raster_strata/.
